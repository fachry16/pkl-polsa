# Anti-slop audit 001

Tanggal: 2026-11-23
Mode: AFTER, session override
Scope: perubahan UI untuk foreign key RPS pada form create/edit, cover, dokumen, PDF, pengajuan, dan widget kaprodi. Termasuk select `ketua_prodi_id` dan `koordinator_rmk_id`.
Status: findings belum diperbaiki.

## Findings

1. HIGH, R-35: Belum ada catatan click-through browser untuk submit create, validasi gagal, preselect edit, dan rendering cover serta PDF. Bukti saat ini hanya test otomatis dan compile Blade.
2. HIGH, R-27: Saat daftar pengampus, ketua prodi, koordinator, dosen, atau rumpun kosong, form hanya menampilkan placeholder select. Tidak ada pesan empty state yang menjelaskan penyebab dan tindakan berikutnya.
3. HIGH, R-03: Perubahan form create/edit belum diverifikasi pada breakpoint mobile. Kelas `w-full` tidak cukup untuk membuktikan tidak ada overflow atau kontrol yang terlalu kecil.
4. HIGH, R-37: Tidak ada `DESIGN.md`. Perubahan kontrol form dan tampilan RPS mengikuti styling existing tanpa direction tertulis dan tanpa label draft.
